# MapleHelper compatibility data

This public repository contains only reviewed client compatibility signatures and version fingerprints. It contains no application source, credentials, character details, chat messages or user settings.

MapleHelper validates downloaded catalogs and the loaded client code before using them. A catalog does not bypass verification or provide attack rectangles.

Catalog schema: 1. Revisions are monotonic and profiles are append-only. New profiles require a maintainer review of client instructions, control flow and references.
